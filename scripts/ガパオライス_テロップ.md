# ガパオライス Shorts テロップ案

S&B シーズニング「ガパオ(タイ風バジル炒め)」使用。
パッケージ裏のレシピ+動画の実際の流れ(約37秒)に合わせたタイミング付き。

## 材料テロップ(冒頭でまとめて出す用)

```
今夜はガパオライス🌿
・鶏ひき肉 160g
・サラダ油 大さじ1
・ガパオの素 1袋
炒めるだけ2分!
```

## タイムライン別テロップ

| 目安時間 | 映像 | テロップ |
|---|---|---|
| 0〜3秒 | パッケージ紹介 | 今夜はコレ!S&Bのガパオの素 🇹🇭 |
| 3〜6秒 | コンソメ・スープ準備 | その間にスープも仕込む |
| 6〜9秒 | 肉カット・ブロッコリー | 副菜も並行調理 |
| 12〜15秒 | ひき肉を炒める | ①油を熱してひき肉を炒める |
| 15〜18秒 | 素を加えて混ぜる | ②火を止めて素を入れて混ぜる |
| 18〜21秒 | さっと炒め+目玉焼き | ③再点火してさっと炒めるだけ |
| 21〜24秒 | 目玉焼きを取り出す | 目玉焼きは外せない🍳 |
| 25〜30秒 | 子ども用プレート盛り付け | 子ども用は辛くないひき肉で |
| 31〜37秒 | 家族全員分の食卓 | 夕食まるごと完成!ごちそうさまでした |

## メモ

- 手順①②③はパッケージ裏の作り方そのまま。「いったん火を止めてから素を混ぜる」のがこの商品のポイントなので、②は省略しない。
- 素は1袋で2人前。子ども用に素を入れる前のひき肉を取り分ける場合は、⑧のテロップ「子ども用は辛くないひき肉で」がその説明になる。
- 締めのテロップは「今日も一日おつかれさまでした」などチャンネル定番の挨拶に差し替えてもOK。
