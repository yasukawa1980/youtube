# トマト胡麻だれチキン Shorts テロップ案

元レシピは maki さんの『トマト胡麻だれチキン』。
むね肉に片栗粉をまぶして焼き、トマト入りの胡麻ポン酢だれで和えるだけのさっぱり系。
動画(縦・約43秒)の流れに合わせてタイミングを付けています。時間は目安なので実際のカットに合わせて調整してください。

## 材料テロップ(冒頭でまとめて出す用)

```
夏でも食べられる さっぱりチキン🍅
・鶏むね肉 1枚
・トマト 1個
・胡麻ポン酢だれ
和えるだけ!
```

## レシピ表(材料・2人分/調理時間10分)

### 胡麻だれ【A】

| 材料 | 分量 |
|---|---|
| トマト | 1個(角切り) |
| すりごま | 大さじ2 |
| 鶏ガラスープの素 | 小さじ1 |
| ごま油 | 小さじ1 |
| ポン酢 | 大さじ3 |
| チューブにんにく | 5cm |
| 刻みネギ | 20g |

### チキン

| 材料 | 分量 |
|---|---|
| 鶏むね肉 | 1枚 |
| 酒 | 大さじ1 |
| 片栗粉 | 大さじ2 |
| サラダ油 | 適量 |

### 手順

1. トマトは角切りにし、ボウルで【A】を混ぜておく。
2. 鶏むね肉を一口大に切り、酒をふってポリ袋に移し、片栗粉をまぶす。フライパンにサラダ油をひいて中火で温め、こんがりと焼く。
3. 焼いた鶏肉と1を合わせて混ぜたら完成。

## タイムライン別テロップ

| 目安時間 | 映像 | テロップ |
|---|---|---|
| 0〜3秒 | 完成カット or むね肉 | 夏バテでも食べられる さっぱりチキン🍅 |
| 3〜7秒 | トマトを角切り | ①トマトを角切りにする |
| 7〜12秒 | ボウルで調味料を混ぜる | ②【A】を全部混ぜて胡麻だれを作る |
| 12〜16秒 | むね肉を一口大にカット | ③むね肉を一口大に切る |
| 16〜20秒 | 酒+片栗粉をポリ袋で | ④酒をふって片栗粉をまぶす |
| 20〜26秒 | フライパンで焼く | ⑤中火でこんがり焼く |
| 26〜31秒 | 焼き上がりを胡麻だれへ | ⑥焼けた鶏肉とだれを和えるだけ |
| 31〜36秒 | 盛り付け | 揚げない・和えるだけでこの満足感 |
| 36〜43秒 | 家族の食卓 | 今日も一日おつかれさまでした🍅 |

## メモ

- むね肉は「酒→片栗粉」の順が大事。片栗粉が薄い衣になって、パサつかず胡麻だれもよくからむ。
- トマトから水分が出るので、和えるのは食べる直前がおすすめ。作り置きなら食べる前に和える。
- 子ども用に取り分けるなら、にんにく少なめ・ポン酢控えめの胡麻だれを別に作ると食べやすい(その説明テロップを入れてもOK)。
- 締めのテロップはチャンネル定番の挨拶に差し替えOK。
- 概要欄などで元レシピ(maki さん)に触れておくと丁寧。
