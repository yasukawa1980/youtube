## 停止理由と実測

| 項目 | V1 |
|---|---:|
| 合成した音声の長さ | **25.537250秒** |
| PCMサンプル数／サンプルレート | 612,894／24,000 Hz |
| 30fpsに切り上げた音声部分 | 767フレーム／25.566667秒 |
| 末尾の登録案内 | 75フレーム／2.5秒 |
| 夜警と同じ構成での予定総尺 | **842フレーム／28.066667秒** |
| 24秒上限からの超過 | **4.066667秒** |
| 声の開始／最後の活動 | 0.06秒／25.22秒 |

音声尺はWAVのサンプル数とffprobeの両方で一致。予定総尺はまだ書き出していないMP4の実測ではなく、夜警ショートの計算式 `ceil(音声秒数 × 30) + 75フレーム` による値。声の活動は10ms窓のRMSが−50dBFSを超える区間で測定した。

台本は依頼書から文字列を直接取り出し、一字も変更していない。依頼書の「52語」に対し、空白区切りの機械的な語数は53語だった。停止判定は語数の推定ではなく新規合成音声の実測による。

本編SSDの `records/queries_en.json` と `narration_segments_en.json` を照合し、**Kokoro af_heart、speed 0.82、sentence_pause 0.3、clause_pause 0.12、読み替え・特別な音素指定なし**を確認。本編と同じ設定を使用し、夜警ショートと同じ `create_timed`・`trim=True` で合成した。本編の記録ではLeutze・Whittredge・Houdon・Düsseldorfにも読み替えはない。V2・V3は停止後に合成しておらず、これらの語の比較音声も未作成。

24秒に合わせるための加速、台本の短縮、間の削除、案内の短縮は実施していない。
