# Codexへの申し送り：保存のしかたと整理のルール（2026-10-17）

このチャンネルの制作は Claude と Codex の両方で行っています。
Claude は GitHub のリポジトリしか見えません。**Mac の中だけに置いたものは Claude には見えません。**
これからは保存のしかたを、これまで Claude がやってきた形にそろえてください。

## 1. Claude にも見えるように保存する

- リポジトリ：`yasukawa1980/youtube`
- ブランチ：**`bgm/production`**（これまでの制作物はすべてここにあります）
- 作業が一区切りしたら、**コミットして push まで** してください。push しないと Claude には見えません。

### リポジトリに入れるもの（文字のファイル・小さい画像）
| もの | 置き場所・名前の付け方（既存の例に合わせる） |
| --- | --- |
| スクリプト | `bgm/bgmkit/` に機能として足すのが第一。単発なら `bgm/<巻>_<内容>.py` |
| 巻の設定 | `bgm/volumes/<巻>.yaml`（小文字・ゼロ埋めなし。例 `vol15.yaml` `doj01.yaml`） |
| 設計メモ | `bgm/<巻>_テーマ設計.md` |
| タイトル・説明文・タグ | `bgm/<巻>_アップロード情報.md`（ショートは `<巻>_ショート_アップロード情報.md`） |
| 画像・音楽のプロンプト | `bgm/<巻>_コピー用プロンプト.md` |
| サムネ（確認用） | 長辺1280px以下の JPG（1枚1MB以下）を `サムネ確認用/<シリーズ>/<巻>_サムネ.jpg` に置く |

### リポジトリに入れないもの
- 動画（mp4）・音源（wav/mp3）・高解像度の素材：Mac/SSD の `BGM/` に置く（下の2.）
- 中間ファイル（`_work/`）
- APIキーなどの秘密情報（`~/.config/bgmkit/env` にだけ置く）

### コミットメッセージの書き方
日本語で、「何をしたか」と実測値を書く。既存の例：
- `feat(wave01): 縦型ショート5本を作る（各45秒 / -14.0〜-14.2 LUFS）`
- `fix(doj01): 画像プロンプトの取り違えを5点直す`
- `docs(soj02): アップロード情報を完成版で作り直す`

## 2. フォルダを順番・シリーズごとに整理する

### Whispers（今の形に合わせる）
Mac `~/Desktop/BGM/` と SSD `/Volumes/ESD-EPB/BGM/` は同じ形にそろえてあります。
```
BGM/
  1_Whispers of Japan/
    Vol01_素材_xxx/ … Vol15_素材_xxx/   ← 巻番号は2桁ゼロ埋め
    LongNights3_素材/
    童謡単曲/                              ← 今回の単曲版はここに新設
      01_夕焼け小焼け/
      02_赤とんぼ/
      03_…/
  2_Sounds of Old Japan/
  3_Days of Old Japan/
  4_Waves of Japan/
  コンピ/
  _共通/（環境音・エンドカード・スクリプト・資料）
```
- 今回作った童謡の単曲版4曲は `1_Whispers of Japan/童謡単曲/` に、公開順の番号を付けて入れる
- 各曲フォルダには、完成動画・サムネ・使った音源をまとめる
- リポジトリ側の名前は `doyo01`〜（例 `bgm/volumes/doyo01.yaml`、`bgm/DOYO01_アップロード情報.md`）

### IRO
- IRO も Whispers と同じ考え方で、**シリーズ別のフォルダ → 番号ゼロ埋めの回フォルダ** に分ける
- リポジトリ側は `iro/` を作り、Whispers の `bgm/` と同じ名前の付け方にする

### 整理するときの約束
1. **動かす前に「今の場所 → 新しい場所」の一覧を作り、本人に確認してもらってから動かす**
2. 削除はしない（不要に見えるものは `_整理待ち/` に移す）
3. 移動したら、yaml や md に書いてあるパスも書き換え、すべてのパスが実在するかを確認する
4. 終わったら一覧と確認結果をコミットメッセージに書いて push する
