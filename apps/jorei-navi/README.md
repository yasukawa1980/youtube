# 条例ナビ 看板・給水（試作版）

屋外広告物（看板）と給水装置工事のルールを、自治体ごとに見比べるWebアプリです。

## 使い方

`index.html` をブラウザで開くだけで動きます。インストールやビルドは不要です。

## できること

- 分野の切り替え（屋外広告物／給水装置工事）
- かんたん判定
  - 看板：自家用広告物の合計面積から、許可が要りそうかの目安を表示
  - 給水：建物の階数から、直結で給水できそうかの目安を表示
- 自治体ごとのルールと、公式資料（出典）へのリンク
- 名前・地方での絞り込み

## データについて

- `data/signage.js`（屋外広告物）、`data/water.js`（給水装置工事）に入っています。
- 掲載は主要都市のみです。
- 屋外広告物の7都市は、2026-11-10〜11に公式資料の原文と照合しました（照合表は一つ上のフォルダの `照合表_大阪市_看板.md`、`照合表_6都市_看板.md`）。文中の「（未確認：…）」は原文で確かめられなかった部分です。
- 給水装置工事の9水道局も、2026-11-11に公式資料の原文と照合しました（照合表は `照合表_給水.md`）。
- 給水の `floors` は、`sure`（条件なしで直結直圧にできる階数）、`cond`（水圧などの条件つきで直結直圧にできる階数）、`boosterMax`（直結増圧の上限。上限の数字がなければ `null`）です。
- 看板の `selfUse.mode` は判断のしかたです。`"total"` は合計面積、`"each"` は1つずつの面積（大阪市）で判断します。
- 値が `null` の項目は画面に「未確認」と表示されます。
- 自治体を増やすときは、`entries` に同じ形のデータを追加してください。

## 注意

内容は目安です。工事や申請の前に、必ず公式資料と所轄の窓口で確認してください。
