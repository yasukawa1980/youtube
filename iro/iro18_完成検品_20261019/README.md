2. 同スクリプト `parts` で合格した2本を並べ、犬の出来事を旧時刻へ入れる。乱数seed18192026、3連続なし。人物ループのクロスフェードなし。

4. `iro/iro18_ショートと投稿文を仕上げる_20261019.py` で4本と日英投稿文を作る。元音声は `完成_20261019/旧投稿用_保全/` のコピーから使用。
5. `iro/iro18_完成品を検品_20261019.py shorts` と `main` で全編デコード・最終AAC通し測定・AACビットストリーム一致を確認。
