## IRO21 で分かった手順の要点

- Suno の生成は **Claude in Chrome**（JS で入力して `button[aria-label="曲を作成"]` を click）。書き出しは**アプリ内ブラウザ**の API（`bgm/IRO/irokit/suno_export_api.js`、localStorage の `__tmpl` 等は入っている）→ `irokit/suno_get.sh`。生成の待ち判定はワークスペース API の**全ページ**を数える（1ページ目だけだと20曲で頭打ちになり、IRO21 は F-02 を二重に送った）
- Kling は Chrome。開始画像の file_upload は**リポジトリ内のパス**しか渡せない（`iro/_work/iro21/` に写して渡した。Git には入れない）。最初のフレーム→「資産」→「アップロード」で同じ画像を2つ選ぶと最初・最後に入る。設定は Kling 3.0／1080p／8秒／ネイティブオーディオ OFF で 64。取得は詳細画面を開いて `output.mp4` の URL を拾い curl
- 主役の楽器は AST（`bgm/.venv-audio-qc`）ではペダルスチールしか判定できなかった。試作の抜粋を本人に聴いてもらうのが確実
- 2時間の書き出しは **`nohup … & disown`** で（`run_in_background` はセッション終了で止まる）。中間物は ESD-02（Mac の空きが 13〜24GB しかない）
- ショートは**4本とも切り抜き（場面・寄り引き）を変える**（同じ位置だと出来事が違っても絵がほぼ同じ＝本人指摘）
- 別の書き出し（EOJ 等）と CPU を取り合うと検品・書き出しが数倍遅くなる
