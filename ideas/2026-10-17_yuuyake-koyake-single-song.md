# 夕焼け小焼け 単曲シリーズ案（ウィスパーズ）

## きっかけ（2026-10-17）

- ウィスパーズ「夕焼け小焼け」のショートが過去最高クラスの再生数
- 理由の仮説は2つ
  1. **童謡そのものが強い**（曲名で検索・おすすめされやすい）
  2. **YouTubeが「誰に見せるか」を判断しやすい**（1曲＝1テーマで分類が明確）

## まず確認すること（YouTube Studio → そのショートの詳細）

| 見る場所 | こうなっていたら |
| --- | --- |
| トラフィックソース | 「ショートフィード」が大半 → 仮説2寄り / 「YouTube検索」が多い → 仮説1寄り |
| 検索キーワード | 「夕焼け小焼け」「童謡」「寝かしつけ」などが出ていれば曲名の力 |
| 視聴者の年齢・時間帯 | 夕方〜夜に伸びている → 寝かしつけ・夕方の需要 |
| 平均視聴率・リピート | 100%超ならループ再生されている → 長尺版の需要あり |
| 他の動画との比較 | 1時間メドレーのショートと比べて差が大きいか |

## やってみること

- **夕焼け小焼けだけの単曲動画を長さ違いで出す**
  - 3〜5分（1〜2コーラス、フルで聴ける版）
  - 10分（ループ）
  - 30分（寝かしつけ・作業用）
- **タイトルは曲名を先頭に**：例「夕焼け小焼け｜ウィスパーズ｜子守唄・寝かしつけ 30分」
- **ショートから長尺へつなぐ**：ショートの「関連動画」に単曲版を設定
- **同じ形式で他の曲もテスト**（1曲ずつ・同じ長さ・同じタイトル形式で比べる）
  - 秋向け：赤とんぼ、紅葉（もみじ）、里の秋、七つの子
  - 定番：ふるさと、ぞうさん、きらきら星
- 1時間メドレーは続ける（単曲版と役割が違う：単曲＝入口、メドレー＝長時間視聴）

## 注意

- 同じ音源をただ繰り返すだけだと「繰り返しの多いコンテンツ」と見なされる可能性 → 30分版はアレンジ違い（歌・ハミング・ピアノ等）を混ぜる、映像に変化をつける
- 「夕焼け小焼け」は作曲（草川信）は著作権切れだが、作詞（中村雨紅、1972年没）はまだ保護期間内の可能性が高い。YouTubeはJASRACと包括契約があるので投稿自体は通常問題ないが、YouTube以外で配信・販売する場合は要確認

## 判断の目安

- 単曲版 vs メドレーを2〜4週間比較し、インプレッション数とクリック率・視聴時間で判断
- 他の童謡の単曲版も伸びる → 仮説1（童謡が強い）
- 夕焼け小焼けだけ伸びる → 曲固有の人気／季節（秋の夕方）要因
