## 1. なぜ第三のシリーズとして分けるか

**[[sounds-of-old-japan-series]] を分けたときと同じ理由**——作り方が根本から違う。

- Whispers の中核 `analyze`/`select`/`order`（キー・息・一致度）は**効く**（音楽だから）
- SOJ の `vet`（環境音の検品）は**要らない**（生成物に検品する対象が無い）
- **どちらにも無い層が1枚増える**——8〜13Hzの信号そのもの

そして**棚が違う**。Whispers と SOJ は「日本語BGM／睡眠BGM」の棚に居るが、
この巻が入るのは **binaural beats / alpha waves の棚**。あそこは
**紫のフラクタル・幾何学マンダラ・光る脳・でかい「8Hz」の数字**で埋まっている。
**和風の実景を1枚置くと、その棚で唯一異質になる。**
SOJ の「混ぜていないことが差別化」と同じ構造の賭け。

**★この棚だけは検索流入が期待できる。** Whispers は検索ほぼ0・自動再生95%
（[[whispers-growth-mechanism]]）だが、`alpha waves` `binaural beats 8hz` は
実在する検索語で、能動的に探されている。**タイトルの作り方をこの巻だけ変える理由**がここにある。

## 2. シリーズの骨格 —— 3本で「起きている」から「深く眠る」まで降りる

| 巻 | 帯域 | うなり | 場面 |
|---|---|---|---|
| **1（本巻）** | **α波** | **12 → 8 Hz** | 薄暮 → 深夜。水面が鏡になる |
| 2 | θ波 | 8 → 4 Hz | 水の中／靄の中。輪郭が無くなる |
| 3 | δ波 | 4 → 1.5 Hz | 闇と、遠い一つの光だけ |

**★各巻が次の巻の始点で終わる。** 1巻の末尾が8Hz、2巻の頭が8Hz。
**再生リストに順に入れると、9時間かけて覚醒から深い睡眠まで一続きに降りる**という
一つの製品になる。流入の95%が「次の動画」（[[whispers-growth-mechanism]]）なので、
**この設計は自動再生の連鎖をそのまま利用できる。** 番号順に並べるだけで機能する。

α波は本来「リラックスした覚醒」の帯域で、睡眠はθとδ。**1巻だけを単体で出すと
睡眠BGMの連鎖に乗れない**が、この3本立てなら1巻は正しく「入口」として働く。

## 3. 三幕の弧 —— 光が落ち、水面が鏡になり、上下が消える

**うなりが12Hzから8Hzへ落ちる3時間を、そのまま画で見せる。**
SOJ01 の「音が遠くこもっていく」に対応する、この巻の弧。

| 幕 | 場面 | 時刻 | うなり | 水面 | 音 |
|---|---|---|---|---|---|
| 一 | 1〜8 | 薄暮 | 12 → 11.0Hz | さざ波。まだ風がある | 笙＋弦のパッド。明るい |
| 二 | 9〜14 | 宵 | 11.0 → 9.5Hz | 波が細かくなる。月が出る | 笙のみ。音数が減る |
| 三 | 15〜22 | 深夜 | 9.5 → 8Hz | **完全な鏡** | 低いドローン。ほぼ動かない |

**★最後の画は「上下が分からない」。** 水面が完全な鏡になり、山も月も対称に映って、
どちらが空でどちらが水か判別できなくなる。**これが8Hz＝α波の底＝覚醒と睡眠の境目の絵。**
3時間の動画で一番長く画面に出るのが最後の1枚で、夜中に目を覚ました人が見るのもそこ。
**輪郭の無い画で終わるのが、この用途では正しい**（SOJ01が「誰も居ない座敷」で終わるのと同じ判断）。

## 4. 画像の禁止事項

**★この巻の禁止は3つが「鏡」から論理的に出てくる。** 破ると三幕が成立しない。

1. **★水面を乱すものを一切出さない。** 人物・鳥・魚・虫・落ち葉・雨。
   **三幕で「完全な鏡」が要る以上、鳥が一羽居るだけで画が嘘になる。**
   SOJ01 は人物を出したが、この巻は逆に無人が要件
2. **★月以外の光源を出さない。** 灯籠・提灯・家の灯り（場面20の一点を除く）。
   二つ目の光があると対称が壊れる
3. **★月の光条（十字のレンズフレア）を禁じる。** AIは月に必ず光条を付けたがるが、
   肉眼にも静止画にも出ない嘘。SOJ01の「雨の縦線」と同じ性質の失敗
4. **文字。** 木札・石碑・灯籠の刻字。[[whispers-title-scheme]] のVol.8山門の事故と同じ構造
5. **現代物。** 電線・電柱・ガードレール・コンクリート護岸・アルミの手すり・ボート小屋

## 5. 音の設計 —— 2層

```
床（22トラック）    Sunoのパッド。track_seconds で 8分17秒まで伸ばす
ビート層（1本）      生成したバイノーラル。3時間 一度も途切れない ← ambient として敷く
```

### ビート層 —— 中心を主調に固定し、左右が3時間かけて寄っていく

**★キャリアは下げない。中心を 196Hz（G3）に固定する。**

当初は搬送波も 200→150Hz へ下げる案だった（実測で198.9→151.1Hz と動くことは確認済み）。
**やめた理由は音律。** 3時間の途中でキャリアは171Hz付近を通り、これは E3(164.8) と
F3(174.6) の中間＝どの音でもない。床が調性を持つ以上、四分音でずれた持続音を
3時間敷き続けることになる。

代わりに **左 = 196 − うなり/2、右 = 196 + うなり/2** とする。中心が常に G3 に乗り、
**うなりが 12→8Hz に落ちるにつれて左右の2音がゆっくり寄っていく。**
「離れていた二つが3時間かけて一つになる」という、この巻の主題そのままの動きになる。

**実測（ffmpeg 8.1.1 で生成して確認済み）**

| 位置 | 左 | 右 | 中心 | うなり |
|---|---|---|---|---|
| 頭 | 190.05Hz | 201.95Hz | **196.00Hz** | 11.88Hz |
| 中 | 191.00Hz | 201.00Hz | **196.00Hz** | 10.00Hz |
| 尻 | 191.95Hz | 200.05Hz | **196.00Hz** | 8.12Hz |

生成は `WAVE01_ビート生成.sh`。

**★床は G を主調にする。** キャリアと衝突させないため。Suno のプロンプトに
`key of G` を必ず入れ、`analyze` の出すキーで検品する。

**★ビートの音量は −28dB。** 「言われれば気づく」濃さ。これを上げると3時間は聴けない。
`ambient.gain_db: -28`。**ただし [[ambient-layer-pipeline]] の通り dB は素材をまたいで
通用しない。** `audio` の末尾に出る実測（帯域ごとの上がり幅）を見て決め直すこと。

**★`duck_db` は絶対に使わない。** SOJ01 と同じ理由。3時間で21回持ち上げるのは21回起こすこと。

### ★要る改修は1箇所だけ

`bgmkit/audio.py` の `_lay_ambient` は、環境音を必ず `_seamless_loop` に通す（537行）。
**これは頭と尻をクロスフェードで貼り合わせる処理**で、素材を繰り返しても折り返しが
聞こえないようにするためのもの。

**3時間のスイープに掛けると壊れる。** 尻（8Hz）が頭（12Hz）の上に重なり、
さらに出来上がりが `total − loop_xfade` に縮むので、末尾4秒に頭の12Hzが戻ってくる。

→ **`ambient.no_loop: true` を足し、素材長が `total` 以上ならループ化を飛ばす。**
数行で済む。副産物として3時間ぶんのループ化処理（数分かかる）も省ける。

### ★出したあとに必ず測ること —— 左右が潰れていないか

どこか1段でモノラルに落ちると**ビート層は無音同然になるが、音は普通に鳴るので気づけない。**
`mux` の完成品に対して左右のピーク周波数を別々に測る。**191.95Hz と 200.05Hz が
別々に立っていれば通っている。**

```bash
for ch in 0 1; do ffmpeg -v error -i 完成品.mp4 -af "pan=mono|c0=c$ch" -f f32le - | python3 -c "
import sys,numpy as np
x=np.frombuffer(sys.stdin.buffer.read(),dtype=np.float32)[-48000*10:]
X=np.abs(np.fft.rfft(x*np.hanning(len(x)))); f=np.fft.rfftfreq(len(x),1/48000)
print(f'{f[X.argmax()]:.2f} Hz')"; done
```

**AACは通る（実測済み）。** 192k・320k のどちらでも 200.000/210.000Hz が
そのまま残った。ジョイントステレオで潰れる心配は不要。

### 数値

| 項目 | 値 | 根拠 |
|---|---|---|
| `crossfade` | 6.0 / `qsin` | SOJ と同じ。等パワーでないと継ぎ目が3dB凹む |
| `target_lufs` | **−16** | SOJ と揃える。3時間を −14 に持ち上げるとリミッタでうねりが平らになる |
| `true_peak` | −1.5 | |
| `mux_gain_db` | **暫定 −0.5** | **純音でAAC段のトゥルーピーク増分を実測: −15.0 → −14.5 dBFS。**雨の+1.0と音楽の+0.2〜0.4の中間。**床を重ねた実体で必ず測り直すこと** |
| `track_seconds` | 497 | 22枚 × 8分17秒 |
| `segmented` | true / `jobs: 3` | 3時間は分割必須。一本で組むとメモリに載らない |

## 6. タイトル

**英語**

```
Moonlit Water Mirror 🌙 Alpha Waves 12Hz to 8Hz, Japanese Ambient | 3 Hours
```

- **この巻だけキーワードを題に入れる。** §1の通り、この棚は検索が効く唯一の棚
- **`12Hz to 8Hz` が最大の差別化。** あの棚は全部が固定周波数で、
  **「降りていく」ことを題で言っている動画がほぼ無い**
- **`Ambient` は名乗ってよい。** 楽器が鳴るので嘘にならない
  （SOJ が外したのは楽器ゼロだったから。[[whispers-title-scheme]] の裏返し）
- **`Sleep` は入れない。** α波は覚醒側の帯域で、この巻の実体は「眠りへ向かう入口」。
  2巻（θ）3巻（δ）で名乗る
- **★効能を書かない。**「集中力が上がる」「不眠に効く」は医療的主張。
  加えてバイノーラルビートのエビデンス自体が弱く結果も割れている。
  **信号の事実（12Hz to 8Hz）だけを書き、用途は「〜のための音楽」に留める**

**日本語ローカライズ**

```
月の水鏡 🌙 α波 12Hzから8Hzへ｜和風アンビエント・作業用BGM｜3時間
```

**和名** — `月の水鏡`（つきのみずかがみ）

**尺の表記は `mux` 後に実測してから確定する。**

## 7. サムネ

- **帯 `WAVES OF JAPAN`** — 実測 **619px**（`tracking.brand: 8`、Cochin 56）。
  右端 x=715 でスクリム右端920に対し **165pxの余裕**。
  参考: `SOUNDS OF OLD JAPAN` は854pxで右端950＝**わずかにはみ出している**
- **題字 `月の水鏡`** — 日本語4字。`title_fit: 800` により**級数190**で描画される
  （`蝉時雨` は3字で200）。ほぼ同じ大きさに収まる
- **尺バッジは描かない**（`pill: false`。YouTubeが右下に必ず重ねる）
- `title_family: jp` を**ジャンルYAMLに書く**。巻の側だけに書くと豆腐（□□□□）になる

**第一候補は場面17（上下対称・水平線が消える）。** 168pxまで落ちても
「対称の一枚」というシルエットだけは残り、**紫のフラクタルだらけの棚で唯一異質になる**。

**★ただし決めるのは実測。** [[whispers-thumbnail-design]] の通り、22枚を168pxに落として
**題字が乗る帯（左スクリム内、x=40〜920）の最大輝度とばらつき**を測ってから選ぶ。
**この巻は特に落ちやすい**——月の映り込みが画面中央から下に伸びるので、
構図によっては左の帯に光の筋が入る。Vol.15が「文字の下に月が入り込む」で候補を落としたのと同じ検査。

**★月は画面の右に置くようプロンプトで固定する。** 左のスクリムを暗いまま保つため。
