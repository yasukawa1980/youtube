## 動画・音声そのものの取得

[GitHubの非公開Draft Release](https://github.com/yasukawa1980/youtube/releases/tag/untagged-d1912ad47b73bf1cfacb) に、全編の確認用MP4と原本AACを再圧縮せず抽出したM4Aを置きました。Gitの履歴には入れていません。

push権限のあるGitHub認証が必要です。Claude Codeが利用している接続でReleaseを取得できるかは未確認です。Gitのcloneだけでは添付メディアを取得できません。

```sh
gh release download wom01-v01-review-20261020 \
  --repo yasukawa1980/youtube --dir /tmp/wom01-v01-review
cd /tmp/wom01-v01-review
sha256sum -c SHA256SUMS.txt
```

404・権限エラーが出た場合は、まず上記の場面画像・発話時刻・音量実測で確認してください。Draftを公開に切り替えたり、認証情報を文書・チャットに書いたりしないでください。

## Claudeにできることと、未確認のこと

- リポジトリの画像を開けるClaude環境では、画面・字幕・資料と台本の対応を確認できます。
- メディア取得と実行ツールが利用できるClaude Code環境では、ffmpeg等で追加の場面抽出・音量解析ができます。
- 音声認識ツールを使う場合は、実際の音声から得た認識結果と合成時の入力文を区別してください。この資料では音声認識は実施していません。
- 声質・抑揚・発音・BGMとの聴感バランスについて、直接聴けない環境では「聴いて確認済み」としないでください。

[Claude公式の対応ファイル一覧](https://support.claude.com/en/articles/8241126-upload-files-to-claude)には画像・文書は載っていますが、MP4・M4Aは載っていません（2026-10-20確認）。メディアの取得経路を設けても、モデルの直接の視聴能力が追加されるわけではありません。
[GitHub公式](https://docs.github.com/en/rest/releases/releases#list-releases)ではDraft Releaseの一覧はpush権限を持つ利用者に限られます。
