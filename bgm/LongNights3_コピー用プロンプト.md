# Long Nights 3 — Moonlit Lantern Path（月夜の灯籠道）コピー用プロンプト集

**Long Nights ラインの3本目。巻数は付けない。** テーマは「**更ける**」。
**3時間版。楽曲は新規生成しない**（Vol.11〜14の未使用153本・7.42時間から60曲を選抜）。
**新しく作るのは画像60枚だけ**です。

## この巻の設計

**灯籠が一つずつ消えていく一夜を、道を上りながら見る。**
差別化の軸は **時間**。既存14本＋コンピ2本は、どれも「場所」か「対象」で差をつけてきた
（地形・構図・視線の向き・線の出どころ・単一の対象）。この巻だけは**時間の経過そのものが被写体**で、
3時間という尺が「長い」ではなく「必要」になる。**60枚を通して、灯っている灯籠の数が減っていく。**

- **章1 宵の口（場面1〜6）** … 全部灯っている。月は東の低空
- **章2 夜が入る（場面7〜12）** … 最初の一基が消える。月が上がる
- **章3 夜半（場面13〜18）** … 半分が消える。月は中天
- **章4 更ける（場面19〜24）** … 残り三基 → 一基。月が西へ傾く
- **章5 明ける（場面25〜30）** … 月が沈み、最後の火が消え、薄明が来る

**場面30は場面1と同構図の薄明版**。最初と最後で同じ絵を見せ、片方は灯り、片方は灯らない。
（同構図の連続はVol.9の場面9・10で実績のある手）

**色の設計はVol.8以来2本目の暖色**。ただしVol.8（紅葉＝画面全体が赤い）とは逆で、
**暖色は火袋の中と足元の1メートルだけ**に閉じ込め、空・木立・遠景は全部青のまま残す。
一覧に並んだとき「青い画面に橙の点が連なっている1枚」になり、168pxで最も効く形になる。

**音の期待を生まない題材**（[[whispers-series-plan]] の判断軸）。
石・炎・苔は音を持たない。**炎は完全に直立させる**——揺れる炎は風の証拠になるので、
Vol.13が霜で「無風の夜」を証明したのと同じ手を、この巻では炎の直立で使う。

## この巻の弱点と、その解き方

| 弱点 | 解き方 |
|---|---|
| **石灯籠には文字が彫られている**（春日大社の献灯は特にそう）。崩れ字の最大リスク | 火袋の窓を「円と三日月」という**実在する意匠で埋める**。Vol.10の掛け軸と同じ「禁止より描かせる」。加えて全プロンプトで彫字を明示的に禁止 |
| **提灯**を出されると必ず漢字が入る | 提灯・吊り灯籠・幟を全部禁止。石灯籠だけで通す |
| **鳥居**を出すとVol.1と被る | 全プロンプトで鳥居と社殿を禁止（道と灯籠と石段だけで構成する） |
| **中国風の塔灯籠**になる | 春日型の各部（基礎・竿・中台・火袋・笠・宝珠）を毎回列挙する |
| **水**（手水鉢・池・流れ）をAIが足したがる | 全プロンプトで水を否定。手水舎は最初から場面に入れない |
| **虫の音**（秋の参道の連想） | 虫を禁止。季節は落葉も霜も無い乾いた夜にする |
| Comp1「月夜の山道」と近い | あちらは自然の山道で登るだけ。こちらは**人が並べた等間隔の灯**と**時間の経過**が主役 |

## A. 画像 60枚

**30場面 × A（引き）/ B（寄り）＝ 60枚。** bgmkit は **画像枚数＝曲数**でないと `build` が止まるので、
60曲に対して60枚が要ります（メモリにあった「30枚・1枚6分」では通りません）。1枚あたり約3分で、
Vol.14（22枚・60分）と同じ間合いです。

### 保存のきまり

- **16:9 で出す**（手生成なので bgmkit の 3:2→16:9 切り出しとガンマ1.3は掛かりません）
- 保存先は `/Volumes/ESD-EPB/Whispers of Japan/LongNights3_素材/画像/`（**SSD**）
- ファイル名は **`long3_01.png` 〜 `long3_60.png`**（下の番号と一致させる）
- **1枚ずつ生成する**

### 毎回チェックすること

- **炎が揺れていないか。** 傾き・ブレ・煙・火の粉が出たら捨てる（風の証拠になる）
- **石に文字が彫られていないか。** 竿・火袋・基礎。1文字でも出たら捨てる
- **提灯・吊り灯籠・幟・注連縄が付いていないか**
- **鳥居や社殿が入っていないか**（Vol.1と被る）
- **中国風の塔になっていないか。** 笠の反りが強すぎる／段が重なっているものは捨てる
- **水が入っていないか**（手水鉢・池・濡れた路面の照り返し）
- **暖色が空や遠景まで届いていないか。** 橙は火袋と足元だけ。届いていたら捨てる
- **暗部が真っ黒に潰れていないか**（章5の25・26・27は特に危ない。石の粒が見えていること）
- **灯っている灯籠の数が、章の進行と合っているか**（下の表のとおり）
- **同じ画像を2回保存していないか**（名前も日時も違うので目では気づけない。MD5で見る）

## C. 素材が揃ったあとの手順

```bash
cd /Users/ryo/youtube/bgm
python3 -m bgmkit analyze long3            # 済み（153本・11,628ペア）
python3 -m bgmkit select  long3            # --write は付けない（コメントが消える）
python3 -m bgmkit order   long3            # 同上。出力を手で long3.yaml に貼る
python3 -m bgmkit audio   long3
python3 -m bgmkit video   long3            # 4.5〜5時間
python3 -m bgmkit mux     long3
python3 -m bgmkit thumb   long3
```

- **作業先はSSD**（`/Volumes/ESD-EPB`）。3時間はピークで15GB前後使い、内蔵の空き23GBでは足りない
- **`audio` の後に実尺を測ってから `thumb` を回す**（`runtime` を直さないと尺バッジがずれる）
- サムネの元画は **場面1A＝`long3_01.png`**（暗闇に点々と続く橙の光）
