# DOYO03〜06 公開日程の方針（2026-10-18 Claude・本人の希望「予約済みの間に割り込ませる」）

Whispers of Japan の現在の予約一覧はリポジトリに無いため、**具体的な日時はCodexがStudioの予約一覧を読んでから埋める**。
ここでは割り込ませ方の決めごとだけを書く。IRO Sounds は別チャンネルなので考慮しない。

## 1. 夕焼け小焼けを最優先で、できるだけ早く
- 伸びたショート（`EIr-g3taMu8`、10/17公開、953回・平均視聴割合75.8%＝10/18の記録）の勢いがあるうちに、関連動画の行き先を作る。ショートの伸びは数日で落ちるので、**10/19〜10/20のどこか**に入れる。
- 公開されればCodexの既存フォローアップ（毎日11時・23時）が関連動画を差し替える。

## 2. 2本目は七つの子に繰り上げる（本人の承認が要る）
- 承認済みの公開順は 夕焼け小焼け → 赤とんぼ → 紅葉 → 七つの子。
- ただし七つの子のショート（`gog-gWhTsS8`）が公開3時間で272回（通常6〜30回）と伸び始めている。夕焼け小焼けと同じ理由で、**七つの子を2本目にする**。
- 変更案：夕焼け小焼け → **七つの子** → 赤とんぼ → 紅葉。
- 七つの子のショートの関連動画も、単曲版の七つの子へ差し替える（夕焼け小焼けと同じやり方）。

## 3. 間隔は1本ごとに2日あける
- 10/18の分析記録の方針どおり、**1本ずつ公開後24・48時間の数字を比べる**ため。毎日出すと、どの1本が効いたか分からなくなる。
- 4本で約1週間（例：1本目 → 2日後 → 2日後 → 2日後）。

## 4. 既存の予約は動かさない
- 空いている日時に入れる。**既存の予約を後ろにずらすことはしない**。
- 同じ日に Whispers の長尺（本編）がある日は避ける。ショートだけの日なら重ねてよい。
- 同じ曲のショートの予約が同じ日にあれば、その日は避ける（同じ曲が並ぶと比べられない）。

## 5. 時刻は夕方18時（日本時間）
- 童謡単曲は日本語で日本の視聴者向け（動画の言語＝日本語）。「夕暮れのひととき」と書いた説明文とも合う。
- その時刻に既存予約があれば、前後1時間の空きに入れる。

## Codexへの作業順
1. Whispers of Japan の Studio で、**今日以降の予約済み動画（長尺・ショート・ライブ）を一覧にする**（日時・種類・題・ID）。
2. 上の1〜5に沿って、4本の公開日時の案を表にし、本人に見せる。
3. **本人が承認するまで、アップロード・予約はしない。**
4. 承認後に予約したら、日時とIDを `DOYO03〜06_アップロード情報.md` に記録してpushする。

## Claudeの確認（2026-10-19）

Codexの予約一覧と提案は方針どおりで、表の読み取りにも矛盾はない。**1点だけ、全体を2日前倒しにする案を出す**（本人が選ぶ）。

### 前倒し案（推奨）
| 順番 | 曲 | 公開日時案（日本時間） | 同日の既存予約 |
|---|---|---|---|
| 1 | 夕焼け小焼け | **2026/10/19（月）19:00** | 長尺 10:00 Autumn Mountain Stream（英語・川の音）、ショート3本 |
| 2 | 七つの子 | **2026/10/21（水）19:00** | ショート3本（長尺なし） |
| 3 | 赤とんぼ | **2026/10/23（金）19:00** | ショート3本（長尺なし） |
| 4 | 紅葉 | **2026/10/25（日）19:00** | ショート3本（長尺なし） |

理由：
- **夕焼け小焼けのショートは今が伸び盛り**（10/17公開）。2日待つと、いちばん人が来ている間に行き先（単曲版）が無いまま過ぎる。
- 10/19の長尺は**英語の川の音（睡眠向け）**で、日本語の童謡とは見る人が違う。登録者57人なので通知の食い合いもほぼ無い。「長尺と同じ日を避ける」は私が立てた決めごとだが、この日に限っては外してよい。
- 10/20の長尺「冬の童謡 1時間」は同じ童謡なので、こちらは避ける（前倒し案でも10/20には入れていない）。
- 赤とんぼ・紅葉も、それぞれのショート（10/20 18:00・10/22 12:00）から**3日後**に単曲版が出る形になり、Codex案（5日後）よりショートの勢いを拾える。

### Codex案のままにする場合
10/21・23・25・27 の19:00。問題はないが、上の理由で2日ずつ遅くなる。

### どちらの案でも
- 予約の直前に、予約一覧に増減がないかをもう一度確かめる（Codex案の注記どおり）。
- 各曲のショートの関連動画は、単曲版の公開後に単曲版へ差し替える（夕焼け小焼け・七つの子・赤とんぼ・紅葉の4本）。いまのフォローアップは夕焼け小焼けだけなので、残り3本も同じ扱いにする。
