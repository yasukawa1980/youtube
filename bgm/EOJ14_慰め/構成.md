## ★コンソレーション第3番は右手の最上声だけを旋律に（`top(1, 2)`）

右手が旋律と内声を一緒に弾くので、そのままでは旋律が8〜9秒に1音しか尺八へ行かなかった（50音）。
打点ごとに右手の一番上の音だけを残し、残りを左手の側へ回すと **70音＝5.8〜6.6秒に1音**になった。

## 音の実測（`bgm/_検品_EOJ14.py`）

| | |
|---|---|
| 尺 | **56分16秒**（3376.7秒） |
| 整音前 | I −14.97 / LRA 7.9 / TP **−0.30** |
| 前段リミッター（−4.8dBFS）後 | I −15.06 / LRA 7.8 / TP −3.62 |
| **整音後（wav）** | **I −14.0 / LRA 7.7 / TP −2.6**（loudnorm は **linear**） |
| DC | **0.000001**（`dcfix` 後） |

★★入力TP −0.30 のまま +1dB 持ち上げると TP −2.0 に収まらず、**loudnorm が dynamic に落ちた**（EOJ11 と同じ）。
まれな箏の打点だけを `alimiter` で先に抑えて linear で掛けた（音量の変化は 0.07LU だけ＝抑えたのは打点だけ）。
リミッターはサンプル値で抑えるので、TP はその1.2dB上に残る（−3.6dBFS 指定 → TP −2.4 で足りず、−4.8 にした）。
曲どうしの音量 元の差 2.1LU → 0.7LU（`SPREAD = 0.35`）。継ぎ目7箇所：6:44 / 13:46 / 20:43 / 27:11 / 33:59 / 41:35 / 48:41。
