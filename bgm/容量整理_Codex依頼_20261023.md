# Codexへの依頼：Mac内蔵・SSDの容量整理（2026-10-23）

以下をそのままCodexに渡す。

---

Mac内蔵ディスクの空きが約500MBしかなく、第5話を作れません。決まった手順で不要なファイルを削除してください。

## 前提
- 方針と対象は、リポジトリ `yasukawa1980/youtube` のブランチ `bgm/production` にある `bgm/容量整理案_20261023.md` に書いてあります。最初に読んでください。本人は「方針B」を選んでいます（10/8以前に公開した回は、完成音源・サムネ・画像・資料を残し、動画・途中素材・`_work` を消す）。
- 削除にはスクリプト `bgm/容量整理_20261023.py` を使います。手作業で `rm` しないでください。一覧にないものも消さないでください。
- Macのローカル履歴とリモートの履歴は分かれています。**`git pull`・`reset`・`force-push` はしないでください。** スクリプトは `git fetch origin bgm/production` のあと、`git show origin/bgm/production:bgm/容量整理_20261023.py > ~/Desktop/容量整理_20261023.py` で取り出します。
- SSDは **ESD-02**（`/Volumes/ESD-02`）です。つながっていなければ、そこで止めて本人に伝えてください。ほかの名前のSSDで代用しないでください。

## 手順
1. `python3 ~/Desktop/容量整理_20261023.py plan` を実行します。この段階では何も消えません。
2. `~/Desktop/容量整理_要約_20261023.txt` の中身を、そのまま本人に見せます。各区分（G1〜G4）の合計と、G4で保留になった回が分かるようにしてください。
3. **本人が「実行してよい」と答えるまで、削除しないでください。** 外したい回を言われたら、`~/Desktop/容量整理_一覧_20261023.tsv` から該当する行を消し、消した行数を伝えます。
4. 承認されたら `python3 ~/Desktop/容量整理_20261023.py execute` を実行します。
5. 次の2つは、それぞれ本人に聞いてから行ってください。
   - Finderの「ゴミ箱を空にする」
   - `~/Library/Caches` の中身の削除。アプリを閉じてから行います。
6. 最後に `df -h /System/Volumes/Data /Volumes/ESD-02` を実行し、整理の前後の空き容量を記録します。

## 記録とpush
- 結果は `bgm/容量整理結果_20261023.md` に書きます。内容は次のとおりです。
  - 各区分ごとの削除量
  - 照合が合わずに残したファイルの件数と例
  - 整理前後の空き容量（実際に測った値だけ。測っていない値は「未測定」と書く）
- pushの手順：`origin/bgm/production` を起点にした一時worktreeを作り、このファイルだけをコミットしてpushします。既存の未送信コミットは送りません。
- コミットメッセージは日本語で書き、何をしたかと実測値を入れます。
- 一覧・要約のTSVとtxtはDesktopに置いたままにし、コミットしません。
- pushに失敗したら、リモートに反映されていないことを本人に伝えてください。
