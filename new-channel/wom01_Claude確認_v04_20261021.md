## Codexへの依頼

### 依頼A：チャンネル名を入れて書き出し直すときに、まとめて行う（優先度：低）

今は書き出し直さない。チャンネル名が決まって `WOM_BRAND` で書き出し直すときに、同じ工程で行う。音声と字幕は変えない。

1. **図解とクレジットの箱を上へ詰める。** 図解13ショットとクレジット1ショットで、一番下の文字が y≤760px 程度に収まるようにする。写真・模写・再現画の41ショットは変更不要。
2. **クレジット画面に日本語の声を加える。** 例：「Japanese narration — VOICEVOX:冥鳴ひまり」。映像は英日共通で、日本語音声の視聴者にも同じ画面が出るため。概要欄・`VOICE_CREDITS.txt` には記載済みなので、規約上は今のままでも足りる見込み。ただし画面でも明示しておくと、見る人に分かりやすい。
3. 確認条件：
   - 英日のSRTを文字サイズ2段階（下記の `FontSize=14` と `26`）で重ね描きする。場面5種類それぞれで、字幕が画面の文字と重ならないこと。
   - 音声トラックのハッシュがv04と同一。
   - フレーム数20,481・共通尺682.7秒が不変。
   ```sh
   ffmpeg -ss <秒> -copyts -i EP001_Anubis_<lang>_v04_1080p30.mp4 \
     -vf "subtitles=EP001_Anubis_<lang>_v04_1080p30.srt:original_size=1920x1080:force_style='FontSize=26,BorderStyle=3,MarginV=12'" \
     -frames:v 1 check_<lang>_<秒>.jpg
   ```
