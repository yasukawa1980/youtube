# wom01 アヌビス v01：Claudeによる映像・音声の確認（2026-10-20）

対象は日本語v01（2026-10-15制作）。Codexが用意した [確認資料](wom01_確認資料_v01_20261020/README.md) と、Draft Releaseの確認用メディアを使った。

## 取得できたもの・できなかったもの

- **Draft Releaseの取得：成功。** 720p確認用MP4とM4Aをダウンロードし、`SHA256SUMS.txt` と照合して2件とも一致した。
  - READMEの `gh release download` は失敗する（Claude Codeの環境ではGitHubのGraphQLが使えないため）。代わりにREST APIで取得できた：
    ```sh
    gh api repos/yasukawa1980/youtube/releases --jq '.[] | select(.tag_name=="wom01-v01-review-20261020") | .assets[] | "\(.id) \(.name)"'
    gh api -H 'Accept: application/octet-stream' repos/yasukawa1980/youtube/releases/assets/<id> > <name>
    ```
- **ffmpegによる測定：実施。** ラウドネス、無音の区間、映像の静止区間、場面の切り替わり。
- **音声認識：できなかった。** モデルの配布元（huggingface.co）が、このクラウド環境のネットワーク設定で遮断されていた。読み間違いの有無は確認できていない。
- **聴感（声質・抑揚・発音の自然さ）：確認していない。** Claudeは音声を聴けない。以下の音声の指摘はすべて数値の測定に基づく。

## 場面画像（58枚）で見えたこと

1. **N14・N19のパピルス（MET 557657）は、文字の列にしか見えない。** 天秤の場面は画面上で判別できない。語りは「心臓」「秤が釣り合えば」なのに、見えるのは文字。英語版では天秤の部分を拡大するか、ナウニのパピルス（548344）の拡大を使う。
2. **同じ画面の使い回しが多い。** 横たわるアヌビス像は4枚、図解「史料・解釈・再現を分ける」は4区間（N03・N10・N24・N26）、「神々の仕事」は4区間、年表は3区間。
3. **史料の写真が小さい。** N23（棺材片）、N25（7.7cmの像）、N14（パピルス）は、画面の2〜3割しか使っていない。暗い余白が多い。
4. **小さい文字はスマホで読めない。** 画像下の注記（「特定の遺跡・出土品を再現した記録画像ではありません」など）、右上の「史料画像」「AI再現イメージ」の表示、出典の行。英語版では右上の表示を大きくし、注記は概要欄に移す。
5. **焼き込み字幕の語中改行を確認した。**（例：「受け入／れられ」「見／張っている」「示／しています」）英語版は焼き込みなしなので解消される。
6. N09でAIのアヌビス立像が映っていた点（v02で修正済み）を、実際の映像でも確認した。

## 英語版・次の書き出しで直すこと（Codexへ）

1. **BGMを上げる。** ナレーション中はナレーションより15〜20 dB小さい程度（目安 −35〜−38 dBFS）、話していない区間はそれより数dB上げる（ダッキング）。統合ラウドネスの目標（−16 LUFS）は維持する。最終判断は本人の試聴。
2. **章の変わり目に間を入れる。** 7つの章の頭で1.5〜2秒、BGMだけの区間を作る。英語は話す速さを本人の試聴で決める（目安 150語/分前後）。
3. **末尾のクレジット5.7秒の無音をなくす。** BGMをフェードアウトさせて終える。
4. **静止画面に動きを付ける。** 図解にも、他の画面と同じゆっくりした拡大・移動を付けるか、要素を順に表示する。1画面が10秒以上動かないようにする。
5. **史料の写真を大きく。** 画面の高さの7割以上を目安にする。N14・N19は天秤の部分を拡大する。
6. **使い回しを減らす。** 同じ図解は1話で2回までにする。N26はv02で削除済み。
7. 本人の試聴でチェックすること：BGMの大きさ、話す速さ、英語の声。
