- 資料は大きく表示（本編：最大1760×820px。ショート：枠 y270〜1130）。余白はB（ぼかし背景）、細部に触れる場面はD（拡大の添え）。
- 動きは小数座標の滑らかな拡大。基準：フレーム間差分のp95÷中央値 ≤2.5（**資料・映像のショットのみ。オープニング・エンドカードは対象外で、共通版のまま変えない**）。
- 画面の文字：見出し・補足文なし。札は英日併記（`MUSEUM OBJECT｜博物館資料`、`AI RECONSTRUCTION｜AIによる再現`、`FACSIMILE｜模写`、`SCHEMATIC｜模式図`）、出典は上部。図解・クレジットの文字は y≤700。
- 素材は所蔵館、または写真作者などの権利者がPD・CC0と明記したものだけ（写真作者の明示は2026-10-23本人了承。クレジットに写真作者を書く）。CC BY-SA・非商用は不可。
- 終了画面はYouTubeの制約で「最後の20秒」以内。第1話・第2話はエンドカード20秒、**第3話からは10秒の共通版v02**（2026-10-23本人指定）。終了画面はエンドカードの開始時刻に合わせる。
- 高評価・チャンネル登録のお願いは、最後の区間で一文だけ、落ち着いた読み方で（2026-10-23本人指定）。冒頭には入れない。

## Claudeの作業環境の制約と回避策

- 動画・音声は、Codexが非公開のDraft Releaseに置く。取得は **Release ID指定のREST** で行う（タグ名での検索や `gh release download` は使えない）：
  ```sh
  gh api repos/yasukawa1980/youtube/releases/<RELEASE_ID> --jq '.assets[] | "\(.id) \(.name)"'
  gh api -H 'Accept: application/octet-stream' repos/yasukawa1980/youtube/releases/assets/<ASSET_ID> > <FILE>
  ```
- 美術館・図書館・YouTube・huggingface.co には接続できない（DNSエラーまたはプロキシの403）。音声認識は使えない。画像の素材探しはCodexに依頼する。
- ffmpeg（libassあり）とPythonは使える。音は聴けないので、聴感は本人の試聴項目とし、数値・画像での確認と区別して書く。
- 一時ファイルはスクラッチパッドに置く。動画・音源はGitに入れない。
