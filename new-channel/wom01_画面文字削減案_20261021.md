# 第1話 画面の英語の文字を減らす案（2026-10-21 Claude・本人承認済み）

## 目的と前提

- 公開は「1本の動画＋英日の音声トラック＋英日の字幕」を基本とする（本人と合意）。映像は1本なので、画面の文字は全言語で共通になる。
- 目標：**日本語の音声・字幕だけで見ても、画面に分からない英文が残らないこと。** 英語の視聴者にとっても、すっきりした画面になる。
- 対象はv05の映像のみ。音声・字幕・55ショットの順序と時刻は変えない。差し替える絵は、既存の素材（博物館画像・再現画・既存の切り出し）だけで作る。新しい画像生成や追加費用はない。
- **2026-10-21 本人承認済み。** 下記「本人の決定」のとおり確定。Codexが制作する。

## 方針と各要素の扱い

| 要素 | 案 | 理由 |
|---|---|---|
| ① 名称・話数 | **残す** | 固有名で、翻訳は不要 |
| ② 見出し | **消す** | 語りと同じ内容で、日本語の視聴者には読めない英文になる。章の区切りはYouTubeのチャプター（概要欄）で示す |
| ③ 種類の札 | **残し、英日併記の短い札にする**：`MUSEUM OBJECT｜博物館資料`、`AI RECONSTRUCTION｜AIによる再現`、`FACSIMILE｜模写`。図解の札（Concept diagram）は消す | 「本物の資料か、再現か」は、このチャンネルの誠実さの土台。どの言語の視聴者にも読める必要がある。数語の固定の札だけは、例外として併記する |
| ④ 補足文 | **消す** | 内容は語り・字幕で伝わっている。留保（「解釈であって証明ではない」など）は語りにも入っている（N05、N24） |
| ⑤ 出典 | **残す**（今の位置・書式のまま） | 館名・作品番号・CC0は固有の表記で、翻訳しない方が正確。利用条件の表示としても必要 |
| ⑥ 図解の文 | **言葉を使わない図に置き換える**（下表） | 図解が画面の文字の大半を占めている |
| ⑦ クレジット | **残す**（v05のまま） | 固有名とライセンス表記が中心で、1ショットだけ。日本語の声も記載済み |

## 変わらないこと

- 音声（英日）、SRT（英150・日136）、尺682.7秒、20,481フレーム、55ショットの順序と開始・終了時刻。
- 写真・模写・再現画の41ショットは、②④を消して③を併記にする以外、絵の配置を変えない。
- サムネ（英語の題字）。言語ごとにサムネを変えられるかは未確認なので、今回は扱わない。

## Codexへの依頼

1. `wom01_multilingual_visuals.py` の `bars()` から見出し（②）と補足文（④）を外す。札（③）を併記の文言にする。図解の札は描かない。
2. `card_image()` の9種類の図解を、上表の「文字なし」の構成に置き換える。素材は `visual_manifest.json` にある既存の画像と切り出しだけを使う。
3. 見出しを消して空いた上部は、名称と出典だけの細い帯にする。絵の表示範囲を広げる場合も、字幕のために画面下 y≥760px には文字を置かない（v05確認の目安 y≤700px を推奨）。
4. 新しいフォルダにv06として書き出す（v05は残す）。新しい非公開Draft Releaseに置き、Release ID指定のRESTで照合する。
